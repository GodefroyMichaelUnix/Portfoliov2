# Michael Godefroy - Portfolio AI Automation Engineer

Portfolio professionnel de Michael Godefroy, AI Automation Engineer & IT Automation. Conception de systèmes d'automatisation résilients et d'agents IA orientés résultats.

## Stack technique

- **Frontend** : React 19, TypeScript, Tailwind CSS, Vite, Motion, Lenis, React Router
- **Backend** : Node.js, Express (API routes & serving static production bundle)
- **Typographies** : Archivo, Instrument Serif, Plus Jakarta Sans, JetBrains Mono

## Lancement

1. Installation des dépendances :
   ```bash
   npm install
   ```

2. Démarrage en développement :
   ```bash
   npm run dev
   ```

3. Build de production :
   ```bash
   npm run build
   ```
